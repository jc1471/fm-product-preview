# Product Preview Component

## Live Demo
- https://fm-product-preview-flax.vercel.app/

## Summary
This project is a responsive Product Preview Component. It is an example of a responsive product card, with media query and rem values being used to ensure responsiveness between devices.

## Tech Stack
- Vanilla HTML/CSS
- React + Vite

## Installation
1. Clone the repo: https://github.com/jc1471/fm-results-summary.git
2. Navigate to the react folder: cd react
3. Install dependencies: npm install
4. Run development server: npm run dev
